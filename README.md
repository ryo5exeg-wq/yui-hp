# 結い 公式ホームページ

放課後等デイサービス・児童発達支援「結い」の公式ホームページです。  
運営：株式会社仁-JIN-（山梨県甲府市・笛吹市）

## 構成

| ファイル | 説明 |
| --- | --- |
| `index.html` | トップページ（事業所紹介・料金・FAQ・お問い合わせフォーム） |
| `parents.html` | 保護者専用ページ（パスワード保護・写真アルバム） |

シンプルな静的HTML/CSS/JSのみで構成されています。ビルド不要。

## ローカルで確認する

`index.html` をブラウザで直接開くだけで動きます。

## 公開先

- GitHub Pages: `https://<ユーザー名>.github.io/<リポジトリ名>/`
- Cloudflare Pages: `https://<プロジェクト名>.pages.dev/`

## 更新方法

1. このリポジトリの該当ファイルをWeb上から編集（鉛筆アイコン）
2. 「Commit changes」で保存
3. 数十秒〜数分で自動的に公開サイトに反映されます

## 保護者ページのパスワード

`parents.html` 内の以下の箇所を編集してください。

```js
var PASSWORD = 'yui2024';
```

> ※ クライアントサイドの簡易ロックです。機密性の高い情報は載せないでください。

## お問い合わせフォームの宛先

`index.html` 内の `mailto:` リンクで宛先メールアドレスを変更できます。

```js
window.location.href = 'mailto:kit.yui.ta0419@gmail.com?subject=...';
```
